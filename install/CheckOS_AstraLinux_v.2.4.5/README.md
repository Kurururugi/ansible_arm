# CheckOS
___

## 1. Назначение ПО
    
ПО предназначено для проверки настроек ОС, включая настройки KICS.
Проверка настроек происходит методом сравнения эталонного и теущего значений определенного параметра.
___

## 2. Запуск ПО

### *Необходимые условия для запуска*
    
Для работы необходимо, чтобы в папке с исполняемым файлом находилась папка с файлами в формате <b>CSV</b>:

    - Standard.csv
    - StandardAdmin.csv
    - StandardCuratorIB.csv
    - StandardNoAdmin.csv
    - StandardOperator.csv
    - KICS.csv
    - Firewall.csv
    

При запуске CheckOS происходит поочередное чтение этих файлов и эталонных значений, чтение текущих значений
и сравнение. Результаты проверки отображаются в соответствующей вкладке.

Дополнительно к настройкам, которые относятся к системе в целом, проводится проверка настроек в отношении
конкретных пользователей:

    - Администратор ОС
    - Куратор ИБ
    - Оператор
    - Не администратор (любой пользователь дополнительно)

    
Для указания имен конкретных пользователей применяется файл <b>settings.ini</b>, находящийся в корне с исполняемым
файлом. Перед запуском ПО в этом файле необходимо указать имена, которые даны пользователям с 
ролями <b>АдминистраторОС</b>, <b>КураторИБ</b>, <b>Оператор</b>, <b>Не администратор</b>. 
Соответствующим вкладкам присваиваются имена согласно именам пользователей.

### *Запуск*

Запуск CheckOS необходимо производить от имени администратора, перейдя в каталог с исполняемым файлом и 
прописав в консоль команду:

```cmd
sudo ./checkOS_Astra
```


### *Возможные проблемы при запуске*

В случае возникновения ошибки, типа:
```cmd
Error while loading shared libraries: libz.so.1: failed to map segment from shared object:
```
Необходимо прописать в консоль следующую команду
```cmd
sudo mount /tmp -o remount,exec
sudo ./checkOS_Astra
```

## 3. Работа с ПО

### *Первый запуск*

При первом запуске программы пользователю выводится окно с текстом лицензионного соглашения, переключателями

- <b>"Я согласен с условиями лицензионного соглашения"</b>
- <b>"Я не согласен с условиями лицензионного соглашения"</b>

и кнопкой <b>Продолжить</b>. 
На этом шаге необходимо выбрать один из предложенных вариантов и нажать кнопку <b>Продолжить</b>.
В случае согласия программа продолжит свое выполнение и начнет сканировать систему, при следующих запусках окно
с лицензионным соглашением выводиться не будет.
В случае несогласия пользователю выведется сообщение о невозможности дальнейшей работы с приложением.


### *Обновление данных*

Чтобы обновить данные в таблице параметров необходимо нажать кнопку <b>Обновить</b>, в правом нижнем углу.


### *Выгрузка отчетов*

Для выгрузки отчетов, необходимо в правом нижнем углу выбрать нужный тип отчета, и нажать кнопку <b>Отчет</b>.
Для выбора типа отчета, в приложении имеются следующие переключатели:

- <b>QR</b> - отображает в новом окне QR-код;
- <b>PDF</b> - сохраняет отчет в формате PDF. Отчет сохраняется в папке <b>Отчеты</b> в корне с исполняемым файлом. 
- <b>CSV</b> - сохраняет отчет в формате CSV. Отчет сохраняется в ZIP-архиве в папке <b>Отчеты</b> в корне с исполняемым файлом.

Имя файла отчета соответствует названию вкладки приложения, из которой происходило формирование отчета.


### *Загрузка отчета*

В случае необходимости загрузки отчета в CheckOS, необходимо в левом верхнем углу нажать 
<b>Файл</b> -> <b>Загрузить отчет</b>, затем, в открывшемся окне выбрать нужный файл в формате <b>CSV</b> и нажать <b>Открыть</b>,
после чего выбранный отчет откроется в приложении.


### *Описание вкладок*

- <b>Общие</b>

  <i>Проверка корректности настройки параметров ОС, указанных в РД-35.240.00-КТН-0430-22 (настройки, требующие ручной проверки, отмечены в интерфейсе ПО)</i>

- <b>Администратор ОС (заменяется на значение из settings.ini)</b>

  <i>Проверка корректности настройки параметров для пользователя с ролью Администратор ОС, указанных в РД-35.240.00-КТН-0430-22</i>

- <b>Куратор ИБ (заменяется на значение из settings.ini)</b>

  <i>Проверка корректности настройки параметров для пользователя с ролью Куратор ИБ, указанных в РД-35.240.00-КТН-0430-22</i>

- <b>Оператор (заменяется на значение из settings.ini)</b>

  <i>Проверка корректности настройки параметров для пользователя с ролью Оператор, указанных в РД-35.240.00-КТН-0430-22</i>

- <b>Не администратор (заменяется на значение из settings.ini)</b>

  <i>Проверка корректности настройки параметров для пользователя с ролью Не администратор, указанных в РД-35.240.00-КТН-0430-22</i>

- <b>АВЗ (KICS)</b>

  <i>Проверка корректности настройки параметров KICS в соответствии с ТТР по установке, настройке и администрированию KICS в АСУТП ОСТ</i>

- <b>Брандмауэр</b>

  <i>Вывод информации о настройках межсетевого экрана (iptables)</i>

- <b>Сетевые интерфейсы</b>

  <i>Вывод информации о сетевых интерфейсах</i>

- <b>Пользователи ОС</b>

  <i>Вывод информации о пользователях и группах пользователей</i>

- <b>Установленное ПО</b>

  <i>Вывод перечня установленных на АРМ (сервер) программных продуктов</i>

- <b>Сервисы ОС</b>

  <i>Вывод перечня и информации о состоянии системных сервисов</i>

- <b>Процессы ОС</b>

  <i>Вывод перечня системных процессов</i>

- <b>Порты</b>

  <i>Вывод перечня открытых портов</i>

- <b>USB устройства</b>

  <i>Вывод информации о USB-устройствах с указанием времени первого подключения, первого и последнего отключения (отображение информации может отличаться в зависимости от версии операционной системы)</i>

- <b>Операционная система</b>

  <i>Вывод информации об ОС с указанием версии, даты установки, последней загрузки</i>
